# 地理院地図 印刷スタジオ

国土地理院の地理院タイルを、**指定した縮尺どおりの大きさ**で A4/A3 などに印刷し、
複数枚をのりしろで貼り合わせて大きな地図にできる Web アプリです。

ブラウザだけで動作し、サーバー側の処理はありません（地図タイルの取得にのみインターネット接続を使用）。

**公開サイト**: <https://kazumic.github.io/gsi-map-print-studio/>（インストール不要）

---

## 特長

- **縮尺を数値で指定**：`1:25,000` と指定すれば、用紙上 1mm = 地表 25m で描画します（基準は印刷範囲の中心緯度）。
- **画面中央が印刷範囲**：プレビューの視点の中心は常に印刷範囲の中心です。地図をドラッグすると印刷範囲も一緒に動き、ダブルクリックした地点を中央に寄せて拡大できます。
- **分割印刷**：最大 8×8（64 枚）まで分割。隣り合うページは「のりしろ」の幅だけ同じ地図を重複して印刷します（分割が1枚のときは、のりしろを使いません）。
- **図名・縮尺・北矢印は全体で1つ**：分割したときは、各ページに繰り返さず、貼り合わせた全体の左上（図名・縮尺）・右上（北矢印）・左下（縮尺バー）・右下（出典）に1つずつ入ります。
- **貼り合わせの案内を紙面に印刷**：のりしろ線、切り取り線、隣接ページ番号、貼り合わせ手順を各ページに印字。
- **実寸確認用の 100mm 目盛**：最上段の各ページに印字。印刷後に定規で測って、倍率がずれていないか確認できます。
- **組立説明書を PDF に同梱**：ページ配置図と手順を 1 ページ目に自動生成。
- **PDF 出力**：指定 DPI で描画した高解像度 PDF をそのまま保存できます。

## 使い方

```bash
npm install
npm run dev      # http://127.0.0.1:5173/
```

本番ビルドは `npm run build`（`dist/` に出力）、確認は `npm run preview` です。

### 別のPCからアクセスする（Tailscale など）

`npm run dev` は全インターフェースで待ち受けるため（`server.host: true`）、同じネットワーク上の端末から
起動時ログの `Network:` に表示される URL でアクセスできます。

```text
➜  Local:   http://localhost:5173/
➜  Network: http://100.x.x.x:5173/      Tailscale
➜  Network: http://192.168.x.x:5173/    イーサネット
```

- IP アドレスに加えて、Tailscale の MagicDNS 名（`<PC名>.<tailnet>.ts.net`）でもアクセスできます。
- `localhost` 以外からも使えるようになったため、HTTP/HTTPS ではなく **http** でアクセスしてください（HTTPS 化はしていません）。
- Windows ファイアウォールで受信がブロックされる場合は、管理者 PowerShell で該当ポートを許可します。

```powershell
New-NetFirewallRule -DisplayName "GSI Map Print Studio (dev)" -Direction Inbound `
  -Protocol TCP -LocalPort 5173,4173 -Action Allow -Profile Private
```

- `strictPort: true` のため、5173 番が使用中だとエラーで停止します（別ポートに自動で切り替わりません）。

### 1. 用紙と縮尺（01 セクション）

| 項目 | 内容 |
| --- | --- |
| 用紙サイズ | A4 / A3 / A2 / A1 / A0 / B4 / B5 / Letter、縦・横 |
| 印刷解像度 | 150 / 200 / 300（推奨）/ 400 / 600 dpi |
| 縮尺 | プリセット（1:2,500〜1:100,000）から選択。「その他」を選ぶと任意の値（500〜500,000）を入力 |
| 外側の余白 | 0〜30mm（初期値 10mm）。プリンターで印刷できない縁を避ける白余白 |
| のりしろ | 0〜30mm（初期値 0mm）。隣のページと重ねる幅。分割が1枚（1×1）のときは使用しません |

余白とのりしろは初期値を変える必要がない限り、設定パネルの「余白・のりしろ」を開いて変更します（閉じたままでも現在値が表示されます）。
のりしろ0mmでは各ページの左端・上端の余白を切り取って端を突き合わせ、重ねて貼りたい場合はのりしろを8〜15mm程度に広げます。

「1枚あたり ○km × ○km の範囲」の表示で、実際に印刷される地図の範囲が確認できます。

### 2. 場所と分割（02 セクション）

- 住所・地名で検索（国土地理院の住所検索 API）、または緯度・経度を直接入力。
  `35.681236, 139.767125` のような小数度、`35°41'02.4"N 139°46'01.6"E` のような度分秒に対応。
- プレビューの画面中央が常に印刷範囲の中心です。地図をドラッグすると印刷範囲も一緒に動くので、印刷したい場所を中央に寄せてください。
  位置の微調整は矢印キー（1mm、Shiftで10mm）、拡大・縮小はホイールか `+` / `-` キー、全体表示は `0` キーでも行えます。
- 分割数は 1枚 / 2×2 / 3×3 / 4×4 のプリセット、または列・行を個別に指定。
- グリッド図をクリックすると、そのページの仕上がりをプレビューできます。

### 3. 地図と仕上がり（03 セクション）

- 地図タイル：標準地図 / 淡色地図 / 写真
- 印刷オプション：図名・縮尺、縮尺バー、北矢印、のりしろ線、裁ち線・トンボ、100mm目盛、組立説明書
- 「PDFを出力」で保存。ファイル名は `図名_1-25000_A4縦_2x2_20261020.pdf` の形式です。

## 印刷と貼り合わせの手順

1. **用紙サイズ**を合わせ、**倍率を「100%（実際のサイズ）」**にします。「用紙に合わせて縮小」は絶対に選ばないでください。
2. **最上段のページの上端**に印刷される 100mm の実寸目盛を定規で測り、100mm になっているか確認します。
   ずれる場合はプリンターの「拡大/縮小」を「なし」にします。
3. フチなし印刷は不要です。印刷後、**内側になる左端・上端の白余白を赤い破線に沿って切り取ります**。
4. のりしろを設定した場合は、のりしろ線（ピンクの破線）に合わせて下になるページを上に重ねて貼ります。
   紙面の「P○ の左端をこの線に合わせる」の案内が貼り位置の目安になります。
   のりしろ 0mm の場合は、切り取った端を下のページの地図の端に隙間なく突き合わせます。
5. 左から右へ、上から下へ貼り、最後に全体を平らな場所で押さえます。

> 余白（外側の余白）は 10mm 程度を推奨します。裁ち線・100mm目盛を印刷するには 4〜5mm 以上の余白が必要です。

## 縮尺の正確さについて

地図タイルは **Web メルカトル（EPSG:3857）** で配信されています。この図法は緯度によって縮尺が変化するため、
本アプリは次の方針で「正確な縮尺」を実現しています。

- **印刷範囲の中心緯度を基準**に、用紙 1mm = 地表 `縮尺分母 / 1000` m となるよう描画します。
  例：1:25,000 なら用紙 1mm = 25m、A4 縦・余白10mm なら地図範囲は 4.75km × 6.925km。
- 基準緯度から離れた上下端では、Web メルカトルの性質により縮尺がわずかに変化します。
  A4・1ページ・1:25,000（東京駅付近）で**最大約 0.04%**（用紙上 0.1mm 程度）、
  2×2 で約 0.08%、3×3 でも 0.5% 未満です。
  この値は画面の「PRINT SPEC」と組立説明書に常時表示されます。
- **タイルの解像度**：印刷解像度に対してタイルが粗い場合は `高画質 / 良好 / 標準 / 粗い` のバッジで警告します。
  粗い場合は縮尺を小さくする（広い範囲にする）か、DPI を下げてください。
- **100mm 実寸目盛**で印刷倍率を必ず確認してください。プリンターの自動拡縮が残る場合があります。

本アプリは国土地理院の地理院タイルを利用した印刷用の参考図です。**測量成果・証明には使用できません。**

### 設定の保存

用紙・縮尺・中心座標などの設定は `localStorage`（キー `gsi-map-print-studio:settings:v2`）に保存されます。
「設定を初期化」で既定値に戻せます。

### 公開（GitHub Pages）

<https://kazumic.github.io/gsi-map-print-studio/> で公開しています。

## 主な制限

- 地図タイルは国土地理院が配信する最大ズーム（z18）までです。それ以上の縮尺では画像が粗くなります。
- 地図タイルの取得にインターネット接続が必要です。オフラインでは動作しません。
- 縮尺の正確さは基準緯度（印刷範囲の中心）での値です。広範囲・高緯度ほど偏差が大きくなります。
- 施設・建物など、地図タイルに描かれていないものは印刷されません。
- 組立説明書は常に A4 縦です。別の用紙を選んだ場合、PDF は「説明書（A4縦）＋地図ページ（選択した用紙）」の混在になります。
- 大判・多分割・高解像度では PDF 生成に時間がかかり、メモリも多く使います（生成中はタブを閉じないでください）。
  A2〜A0 などの大判で画素数が多くなりすぎる場合は、用紙の寸法（縮尺）はそのままに、出力解像度を自動で下げます。
  実際の解像度は「PRINT SPEC」の出力欄に表示されます。

## 出典

- 地図：国土地理院 [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（標準地図・淡色地図・写真）
- 地名検索：国土地理院 [住所検索 API](https://msearch.gsi.go.jp/address-search/AddressSearch)
- タイルの利用にあたっては[地理院タイルの利用規約](https://www.gsi.go.jp/LAW/2930-takuchijouhoukijun.html)に従ってください。

本アプリの座標・縮尺計算は Web メルカトル（EPSG:3857）に基づき、WGS84 の緯度経度で入出力します。
